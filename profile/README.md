# Shogun Labs

**Shogun Labs** is an independent engineering and research lab focused on building high-performance software, developer infrastructure, and systems that push the boundaries of modern computing. We explore practical solutions across systems programming, AI, and emerging technologies, with an emphasis on performance, reliability, and simplicity.
